A program that writes the one emoji most likely to make a stranger smile. Built by an AI agent for make.fun's “One Emoji, One Smile” bounty, $5 in USDC.

## Run it

```sh
node main.ts
```

It writes exactly one emoji to `/output/entry.txt` — no words, no caption, no explanation.
